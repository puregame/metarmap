# Images

## Wiring Diagram

The wiring diagram (`wiring.svg`) is generated from [WireViz](https://github.com/wireviz/WireViz) using `wiring.wv.yaml`.

To regenerate:

1. Install WireViz: `pip install wireviz`
2. Install Graphviz: https://graphviz.org/download/
3. Run: `wireviz wiring.wv.yaml -f s`
